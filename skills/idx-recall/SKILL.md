# idx-recall

利用者が過去の会話や資料の内容を尋ねたときに、étoile index の索引を引いて答える。

## 発火条件

- 「〇〇の経緯を思い出して」「前に決めた△△」「〇〇の話はどのスレッドだった？」
- 「〇〇について以前どう整理した？」「〇〇の決定事項を確認したい」
- プロジェクト名・取引先名・案件名を挙げて過去の文脈を求めているとき

## 手順

1. 質問から検索語を組み立てる。固有名詞（案件名・人名・法人名）と主題語を残し、助詞や「思い出して」などの動詞は落とす。
2. まず `recall(question=<検索語>, limit=5)` を呼ぶ。
   - 絞り込みたいときは `search` をクエリ言語で使う。例: `project:案件名 after:2026-01 決定`、`tag:補助金 -tag:草案`。
   - 結果が0件なら語を短くする（3文字以上の語は部分一致で当たる）。言い換えでも試す。
3. 返ってきた各件の `title` `updated` `project` `summary` `decisions` `excerpt` を読み、質問に答える。
4. 本文をもっと読む必要があれば `read(id)` を呼ぶ。
5. 回答には必ず根拠を添える。形式は次のとおり。

```
（答え。決定事項があれば箇条書き）

根拠:
- 2026-04-10  青空商店 Webリニューアル / 青空商店 サイト刷新の方針整理
- 2026-06-15  青空商店 Webリニューアル / 青空商店 補助金で写真撮影をまかなえるか
```

## 注意

- 索引に無いことを推測で補わない。見つからなければ「索引には見当たらない」と言う。
- 複数のプロジェクトにまたがる結果は、プロジェクト名を明示して分けて示す。
- `recall` は参照回数（recall_count）を加算する。ランキングに使われるので、実際に根拠にした件だけを引くようにし、無闇に大量に呼ばない。
- 装飾（絵文字・色・太字の乱用）は使わない。黒字のテキストのみ。
