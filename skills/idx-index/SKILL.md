# idx-index

会話の終わりに、そのスレッドの要点を索引に残す。生成物は黒字テキストのみ（装飾なし）。

## 発火条件

- 「索引して」「この会話を索引に入れて」「要点を残して」「決定事項をまとめて索引へ」

## 手順

1. 会話全体を読み返し、次を作る。
   - summary: 3行以内の要点。何を話し、何が決まり、何が残っているか。
   - decisions: 決定事項の箇条書き（決まったことだけ。検討中は入れない）。0件でもよい。
   - keywords: 固有名詞・用語を5〜10個（案件名、制度名、成果物名、場所など）。
   - tags: 分類用の短い語を1〜5個（例: 補助金, 協賛, 設計, 見積, 草案）。既存タグがあれば揃える。`search(query="tag:候補")` で既存の使われ方を確認できる。
   - people: 会話に登場した人物（「〇〇さん」形式）。分かる範囲で。
2. スレッドの id を特定する。
   - claude.ai の URL `https://claude.ai/chat/<uuid>` の uuid がそのまま id。
   - 分からなければ `search(query="<タイトルの一部>")` で探し、利用者に確認する。
   - まだエクスポート・取り込みされていないスレッドは索引に存在しない。その場合は「次回 `idx import` した後に反映される」ことを伝え、生成した要点を本文に残しておく（取り込み後に `index_note` を呼べばよい）。
3. `index_note(thread_id, summary, decisions, keywords, tags, people)` を呼ぶ。リスト属性は既存に追記される（置き換えたいときは `replace=true`）。
4. 書き込んだ内容を、そのまま黒字で利用者に見せる。

## 出力例

```
要点:
サイト刷新のトップページ構成を整理した。営業時間を最上部、写真ギャラリーを追加。公開は5月末。

決定事項:
- トップページ最上部に営業時間を置く
- 写真ギャラリーを追加する
- 公開日は5月末

キーワード: 青空商店, サイト刷新, トップページ, 写真ギャラリー, 公開日
タグ: Web, 設計
人物: 田中さん
```

## 注意

- 要点は事実だけを書く。感想や評価は入れない。
- 個人情報（電話番号・住所・口座など）は要点・キーワードに含めない。
- 見出しや強調に色や絵文字を使わない。
